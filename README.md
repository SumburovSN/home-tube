Проект по шаблону YouTube для домашнего видео.
Домашнее видео должно быть перемещено в папку public/videos/
Каталог статичный. Для каждой группы видео создается json в папке src\data\videos\"".js по типу:
"
export const leopold = [
  {
    title: '1. Леопольд и золотая рыбка',
    category: 'Леопольд',
    categoryId: 'leopold',
    duration: '00:15:30',
    video: '/videos/leopold/01.leopold_i_zolotaya_rybka.mp4',
    thumbnail: '/thumbnails/01.leopold_i_zolotaya_rybka.jpg',
  },
]
"
и импортируется в src\data\videos\index.js по типу:
"
import { music } from './music';
...

export const videos = createVideoCatalog(
  ...
  music,
);
"
